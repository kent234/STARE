## [0.6.0]
### ✨ Добавлено (Added)
- **Боковая панель (Sidebar)**: При клике на узел графа выезжает панель `[ NODE.INFO ]` с подробной информацией.
- **Красивый JSON-вьюер**: Собственный React-компонент для подсветки синтаксиса JSON (цветные ключи, строки, цифры) в боковой панели.
- **Сбор баннеров (Banners)**: Go-бэкенд теперь собирает версии сервисов (Nginx, OpenSSH, IIS) и отображает их при клике на порт.
- **Связь Поддомен -> IP**: Граф теперь отображает, на какие конкретно IP-адреса резолвятся поддомены.

### 🔄 Изменено (Changed)
- Улучшена логика тултипов при наведении на узлы графа.
- Переработан `GraphVisualizer.jsx` для поддержки новых данных.

---

## [0.5.0]
### ✨ Добавлено (Added)
- **Go REST API**: Создан новый сервер (`cmd/stare-api`) для взаимодействия с фронтендом.
- **Вынос логики**: Ядро сканера вынесено в отдельный файл `engine.go`.
- **Cytoscape.js**: Интегрирована библиотека для отрисовки интерактивного графа связей (Домен -> IP -> Порты).
- **React Fetch**: Веб-интерфейс научился отправлять POST-запросы на Go-сервер и получать реальные данные.

### 🐛 Исправлено (Fixed)
- Ошибка `destroy is not a function` в `useEffect` при размонтировании компонента графа.
- Проблема схлопывания контейнера графа (добавлен `flex: 1` и `min-height: 0`).

---

## [0.4.0]
### ✨ Добавлено (Added)
- **Веб-интерфейс (MVP)**: Инициализирован проект на React + Vite.
- **StartScreen**: Главный экран с ASCII-Землёй, VHS-глитч эффектом для логотипа и CRT-сканлайнами.
- **MainScreen**: Панель управления в стиле хакерского терминала с имитацией логов и полем ввода цели.

---

## [0.3.0]
### ✨ Добавлено (Added)
- **Интерактивный CLI**: Добавлен интерфейс командной строки с ASCII-баннером, матричным дождём и спиннерами.
- **Deep Scan (Рекурсивный анализ)**: Модуль для сканирования портов и заголовков на каждом найденном поддомене.
- **Экспорт в JSON**: Автоматическое сохранение результатов каждого скана в файл.

---

## [0.2.0]
### ✨ Добавлено (Added)
- **Новые источники OSINT**: Интегрированы `crt.name`, `RapidDNS`, `TLSCC`, `HackerTarget`, `AlienVault OTX`, `ThreatMiner`, `URLScan`.
- **Универсальный WHOIS/RDAP**: Поддержка любых доменных зон через IANA Bootstrap.
- **Wappalyzer**: Определение технологического стека (CMS, фреймворки, серверы).
- **Nuclei**: Интеграция сканера уязвимостей (поиск CVE).
- **Поддержка IDN (.рф)**: Конвертация кириллических доменов в Punycode.

---

## [0.1.0]
### ✨ Добавлено (Added)
- **Ядро сканера на Go**: Создан базовый модуль `scanner`.
- **crt.sh**: Парсер поддоменов через Certificate Transparency.
- **DNS-резолвер**: Базовый резолвинг A/AAAA записей.
- **Wordlist Brute-force**: Перебор поддоменов по словарю (5000 слов) с защитой от Wildcard DNS.
- **Сканер портов**: Проверка базовых портов (80, 443, 22, 3389 и др.) с использованием Worker Pool.
